このシートを横に開き、**上から順に貼り付けるだけ**。考える作業はゼロ。所要15分。
（背景説明が欲しくなったら `coconala-account-guide.md` を参照）

> 貼り付け前に決めること1つだけ: 屋号（例では `moromi` を使用。自分の屋号に読み替える）

## 画面2: プロフィール

**キャッチフレーズ**:
```
面倒な手作業、ツールにして自動化します
```

**自己紹介**:
```
業務自動化・データ整形・Webの軽微修正を専門にしています。
「これ、手作業でやり続けるの大変だな」という作業をツールにするのが得意です。
最新の開発支援ツールを活用し、スピーディに、かつ納品前の動作確認は必ず人の手で行っています。
小さなご依頼こそ歓迎です。まずはお気軽にご相談ください。
```

**スキル（選択式）**: Google Apps Script / Python / HTML・CSS / スプレッドシート
**稼働情報**: 週末中心・返信は24時間以内

## 画面3: 本人確認・振込先

- 本人確認書類: 運転免許証など（本人操作）
- 振込先: 沖縄銀行・（支店名）・（口座番号）・名義カタカナ
  - ※ 出品者情報の「氏名フリガナ」と口座名義のカタカナを一致させること
  - ※ 出金は3,000円以上貯めてから申請（未満だと手数料160円）
