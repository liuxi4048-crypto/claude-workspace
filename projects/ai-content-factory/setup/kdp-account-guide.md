# KDP（Kindle ダイレクト・パブリッシング）アカウント開設ガイド

> **この工程だけ自動化しない理由**: KDP は銀行口座・税務情報（マイナンバー関連の税務インタビュー）の本人確認が必須で、代理・自動登録は規約違反＝**アカウント停止（＝全書籍削除）の対象**。所要 **15分・1回だけ**。入力内容は下に全部用意してあるので、画面の順にコピペ・選択するだけ。

## 事前に手元に用意するもの

- プロジェクト専用 Google アカウントの Gmail アドレス（`google-account-guide.md` で作成済み）
- 銀行口座情報（振込先。ネット銀行可。**本人名義であること**）
- マイナンバー（税務インタビューで使う場合がある）

## 手順1: Amazon アカウント（15分のうち5分）

1. https://kdp.amazon.co.jp を開く → 「サインアップ」
2. **既存の買い物用 Amazon アカウントとは別に作るのを推奨**: 「Amazonアカウントを作成」で専用 Gmail を使用
   - 名前: 本名（支払・税務があるため。ペンネームは本ごとに別途設定できるので、ここは本名でよい）
3. メール認証・SMS 認証を完了

## 手順2: アカウント情報の入力（5分）

KDP ダッシュボード上部の「アカウント情報が不完全です」→ 今すぐ更新 から:

| 画面の項目 | 入力する内容 |
|-----------|------------|
| 国/地域 | 日本 |
| 氏名・住所 | 本名・現住所（公開されない） |
| 電話番号 | 自分の携帯番号 |

## 手順3: 支払いの受け取り方法（2分）

| 画面の項目 | 入力する内容 |
|-----------|------------|
| 銀行の所在地 | 日本 |
| 口座情報 | 銀行名・支店・口座番号・**本人名義** |
| 対象マーケットプレイス | 「すべてに適用」を選択 |

## 手順4: 税に関する情報（税務インタビュー・3分）

英語画面が出ても慌てない。個人・日本居住者なら:

| 質問 | 回答 |
|------|------|
| 納税区分 | Individual（個人） |
| 米国人か | No |
| 居住国 | Japan |
| 納税者番号（TIN） | 日本のマイナンバーを入力（租税条約の軽減税率を受けるため推奨） |
| 署名 | 電子署名（自分の名前をタイプ） |

> マイナンバーを入れると日米租税条約により米国源泉徴収 30% → 0% になる。入れない場合は米国での売上に 30% 源泉徴収がかかる。
