# ココナラ アカウント開設ガイド

> **この工程だけ自動化しない理由**: ココナラは電話番号認証＋本人確認があり、規約で自動化アクセス・代理登録を禁止。違反は**アカウント停止＝実績と売上金が凍る**。所要 **15分・1回だけ**。プロフィール文・出品文はすべて `../coconala/listings.md` に用意済みなのでコピペで終わる。

## 手順1: 会員登録（3分）

1. https://coconala.com → 「会員登録」
2. メールアドレス: プロジェクト専用 Gmail を使用
3. ユーザー名: 屋号系（例: `moromi_works`）。**出品者として客に見える名前**なので信頼感優先
4. SMS 認証を完了

## 手順2: プロフィール設定（7分）

出品者として売れるかはプロフィールの充実度で大きく変わる。

| 項目 | 入力する内容 |
|------|------------|
| アイコン | 無地ロゴ的な画像（未設定は信頼度が下がる。Canva で1分で作るか、表紙ジェネレータの配色で作った正方形画像でも可） |
| キャッチフレーズ | 「面倒な手作業、ツールにして自動化します」 |
| 自己紹介文 | `../coconala/listings.md` の「プロフィール文（共通）」をコピペ |
| スキル | Google Apps Script / Python / HTML・CSS / スプレッドシート |
| 稼働情報 | 週末中心・返信は24時間以内（← 守れる範囲で正直に書く） |

## 手順3: 本人確認と振込先（3分）

- マイページ → 本人確認書類の提出（運転免許証など。出品ランク・信頼度に影響するので済ませておく）
- 振込先口座: 本人名義の口座を登録

## 手順4: 出品（2分 × 3本）

「出品する」→ カテゴリは「IT・プログラミング・開発」系を選び、
`../coconala/listings.md` の出品①②③をそのままコピペ:

1. スプレッドシート/GAS 自動化（5,000円〜）
2. Web ページの軽微修正（3,000円〜）
3. CSV・データ整形スクリプト（4,000円〜）

> **注意（規約）**: 文章作成・記事・リライト系のサービスは出品しない（AI 生成文章はココナラの禁止コンテンツ例に該当）。出品前に最新の出品ガイドラインを一読すること。

## 完了チェック

- [ ] 本人確認済みバッジが付いた
- [ ] 出品3本が公開状態になった
- [ ] 公開依頼（リクエストボード）の閲覧をブックマークした（提案は `../coconala/proposal-templates.md` を使う）
- [ ] 登録情報を `progress.md` にメモした

## 受注後の流れ（毎回）

1. ヒアリング: `../coconala/proposal-templates.md` のテンプレを送る
2. 制作: Claude Code に依頼文とサンプルデータを渡して開発
3. 納品前: `../coconala/delivery-checklist.md` を**人手で完走**（必須）
4. 記録: work_logs/ に案件記録
