# 提案文・ヒアリングテンプレート

公開依頼（リクエストボード）への提案や、DM での見積り相談に使うテンプレ。
**送る前に必ず案件内容に合わせて2〜3文カスタマイズする**（テンプレ丸出しの提案は通らない）。

## 提案文テンプレ（公開依頼向け）

```
はじめまして。業務自動化・データ整形を専門にしております。

ご依頼の「{案件タイトル}」について、
{★カスタマイズ必須: 依頼文から読み取った具体的な理解を1〜2文。
例: 毎週のフォーム集計を手作業で転記されているとのこと、
GAS で自動化すれば毎週の作業がゼロにできる内容と拝見しました}

【ご提案】
・実現方法: {GAS / Python スクリプト / HTML修正 など}
・金額: {金額}円
・納期: ご発注から{N}日
・納品後1週間は無償で不具合対応いたします

【進め方】
1. 現状の{シート/ファイル/ページ}を拝見（機密部分はダミーで結構です）
2. 完成イメージをすり合わせてから着手します
3. お客様の環境での動作確認まで行って納品します

ご不明点があればお気軽にご質問ください。
どうぞよろしくお願いいたします。
```

## ヒアリング質問テンプレ（受注直後に送る）

```
ご発注ありがとうございます。スムーズに進めるため、以下を教えてください。

1. 現状: 今はどのような手順で作業されていますか？（箇条書きで結構です）
2. ゴール: 完成したら「何がどうなっていれば成功」でしょうか？
3. 対象データ/ページ: サンプルを共有いただけますか？（機密部分はダミー可）
4. 実行環境: {Google アカウント / Windows・Mac / サーバーへのアクセス手段} はありますか？
5. 期限: いつまでに必要でしょうか？

いただいた内容で仕様をまとめ、着手前に一度ご確認いただきます。
```

## 着手前の仕様確認テンプレ

```
ヒアリングありがとうございました。以下の内容で作成します。

【作るもの】{1〜3行で明確に}
【できること】{箇条書き}
【今回の対象外】{スコープ外を必ず明記 — 追加要望の膨張を防ぐ}
【納期】{日付}

この内容でよろしければ「OK」とご返信ください。着手いたします。
```

## 運用メモ

- 提案は「相手の依頼文を読んだことが伝わる1〜2文」が通過率を決める。Claude に依頼文を渡して下書きさせ、ユーザーが最終確認して送る
- 金額に迷ったら実績づくり期は下限寄り（出品①5,000 / ②3,000 / ③4,000円）
- **対象外の明記を絶対に省かない**（週5時間体制では修正往復の膨張が最大のリスク）
- 同時1件の上限に達している間は新規提案を送らない
