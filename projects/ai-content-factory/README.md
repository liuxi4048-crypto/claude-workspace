# AIコンテンツ工房 — 事業計画書

Claude Code サブスクを活用した二本柱の収益プロジェクト。
**主軸: Kindle出版（資産型）** ＋ **サブ: ココナラ小型受託（即金型・実績づくり）**

## 前提条件

| 項目 | 内容 |
|------|------|
| 稼働時間 | 週5時間以下（Claude Code が制作の8割を担当、本人はレビューと手作業のみ） |
| 目標 | 3ヶ月以内に初売上（**初売上が立てば成功**のライン） |
| スキル前提 | 実績ゼロからスタート |
| 運転方法 | `/content-factory` スキルで週次運転 |

## 収益見込み（保守的）

- **3ヶ月時点**: ほぼゼロ〜数千円が実態ライン。Kindle 2〜3冊の印税＋受託1件（3,000〜10,000円）が取れれば上出来
- **6ヶ月以降**: 月1〜5万円圏は「冊数10冊前後＋ニッチ的中」が前提の上振れシナリオ
- 基本戦略: **低コストで冊数を積み、売れたニッチに寄せる**。すぐ大金は狙わない

## 規約チェックリスト（毎回の出版・出品前に確認）

- [ ] **KDP: 「AI-generated」として申告する**
  - Claude Code が原稿の大半を執筆するモデルは、後から大幅に編集しても KDP の定義上「AI-generated」（「AI-assisted」ではない）
  - 未申告は書籍削除・アカウント停止リスク（執行強化中）。申告は Amazon 内部用で商品ページには表示されず、正しく申告すれば出版自体は問題ない
- [ ] **表紙に AI 画像生成を使った場合、表紙も申告対象**（Canva 手動作成なら申告不要）
- [ ] **ココナラ: コード納品系のみ出品**（GAS・スクリプト・Web修正）
  - ココナラは「AIにより生成した文章の記事」を出品禁止コンテンツ例に含み、AI 判定システムを導入している。文章系（記事作成・リライト）は出品しない
- [ ] 納品物は必ず人手レビュー・動作確認してから納品（`coconala/delivery-checklist.md`）
- [ ] Claude サブスクの生成物は商用利用可。ただしサブスクを第三者向け API として転用しない
- [ ] 規約は変わる。四半期に一度、KDP コンテンツガイドラインとココナラ利用規約の最新版を確認する

## 受託の上限ルール

顧客対応（ヒアリング・修正往復・納期管理）は自動化できず、1件で週2〜3時間を消費しうる。

- **同時1件・月1件まで**。超過分は辞退または翌月に回す
- 主軸はあくまで Kindle パイプライン。受託が Kindle の週次レビュー時間を圧迫したら受注を止める

## 90日ロードマップ

### Week 1–2: セットアップ
- [ ] KDP アカウント作成（ユーザー作業・無料）
- [ ] ココナラ会員登録・プロフィール整備（ユーザー作業・無料）
- [ ] `kindle/niche-research.md` の企画3案から1冊目を決定
- [ ] ココナラにコード系出品文3本を公開（`coconala/listings.md`）

### Week 3–6: 1冊目出版＋営業開始
- [ ] 1冊目を執筆（週1〜2章レビューのペース、Claude がドラフト生成）
- [ ] 表紙を Canva で作成（`kindle/templates/cover-workflow.md`）
- [ ] KDP 入稿・**AI-generated 申告**・出版（価格 250〜1,250円で70%ロイヤリティ帯、KDP セレクト登録で Kindle Unlimited 既読ページ収益も獲得）
- [ ] ココナラで提案送付を開始（同時1件まで）

### Week 7–12: 量産と絞り込み
- [ ] 2〜3冊目を出版（売れ行きデータ＝既読ページ数・販売数でニッチを絞る）
- [ ] 受託は実績（評価3件）が付いたら値上げ or 継続判断
- [ ] 12週目にレビュー: 初売上が立っているか／どのニッチが反応したか／継続・撤退・転換の判断

## KPI（週次で記録）

| 指標 | 目標（12週時点） |
|------|------|
| 出版冊数 | 2〜3冊 |
| Kindle 収益（販売＋既読ページ） | 初売上が立っていること |
| ココナラ受注件数 | 1件以上 |
| 週あたり本人稼働時間 | 5時間以下を維持 |

## 運用ルール

- 週次運転は `/content-factory` で起動（進捗把握 → 今週のタスク提示 → Claude 側作業は即実行）
- タスク完了ごとに `work_logs/` へ記録（CLAUDE.md の運用に準拠）
- ユーザーの手作業は「レビュー」「KDP 入稿」「Canva 表紙」「ココナラ操作」のみに限定する
