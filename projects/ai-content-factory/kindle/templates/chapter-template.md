# 章の執筆テンプレート

1冊 = 6〜8章、各章 3,000〜4,000字、合計 2.5〜3万字の短め実用書を標準とする。
（Kindle Unlimited の既読ページ収益と週5時間レビュー体制に最適化した分量）

## 執筆フロー（1章あたり）

1. **構成案**（Claude が生成 → ユーザー確認 1〜2分）
2. **ドラフト**（Claude が生成）
3. **レビュー**（ユーザー 10〜15分。下のレビュー観点に沿ってコメントするだけでよい）
4. **修正・確定**（Claude が反映）

## 章の構造テンプレ

```markdown
# 第◯章 {章タイトル — 読者の悩みを言い切る形にする}

## この章でできるようになること
- {具体的な成果を2〜3個。「〜の文例が10分で作れる」のように数字を入れる}

## {本文セクション1: なぜ / 前提}
{200〜400字。理屈は最小限に}

## {本文セクション2〜4: 手順}
{1手順 = 1見出し。「①開く → ②入力する → ③コピーする」の粒度で書く}
{コピペで使えるプロンプト文例・文面テンプレを必ず1つ以上入れる}

> 📋 そのまま使える文例
> {読者がコピペできるブロック}

## つまずきポイント
{よくある失敗と対処を2〜3個}

## この章のまとめ
- {箇条書き3行以内}
```

## レビュー観点（ユーザー用チェックリスト）

- [ ] 想定読者が置いてけぼりになる専門用語がないか
- [ ] 手順は実機で再現できるか（1つでいいので実際に試す）
- [ ] 文例・プロンプトはコピペしてそのまま動くか
- [ ] 誇大な表現（「必ず稼げる」「絶対」）がないか
- [ ] 誤情報リスクのある記述（医療・法律・金額）に免責の一言があるか

## 文体ルール

- です・ます調。1文は60字以内を目安に短く
- 見出しだけ拾い読みしても流れがわかるようにする
- 各章に最低1つ「そのまま使える文例」ブロックを入れる（この本の価値の核）
