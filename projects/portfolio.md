# プロジェクト・ポートフォリオ

全収益プロジェクトのレジストリ。`/content-factory` は起動時にまずこのファイルを読み、
**active な全プロジェクトを横断して**今週のタスクを組む。

## 運用ルール

- **新プロジェクトの追加** = ①`projects/<name>/` を作る ②その中に共通フォーマットの `progress.md` を置く ③下の表に1行追加する。これだけで週次運転の対象になる
- 状態は `active` / `paused` / `done`。paused・done は週次運転でスキップされる
- **グローバル制約（全プロジェクト共有）**:
  - ユーザーの合計作業時間: **週5時間以下**
  - 受託の同時受注: **全体で1件まで**（どのプロジェクト由来でも合算）
- 時間配分は「ユーザー作業時間」の配分。Claude 側の作業量はこの制約に含まれない（独立なタスクは並列実行してよい）

## progress.md 共通フォーマット

各プロジェクトの `progress.md` は先頭に必ずこの「現在地サマリー」を置く（キーは固定・機械的に読めるように）:

```markdown
## 現在地サマリー
- **フェーズ**: {Week N / マイルストーン名}
- **成果物**: {出版済みN冊・出品N本 など数えられる形で}
- **売上（累計）**: {N 円}
- **稼働中の受託**: {N件}（グローバル上限: 全体で1件）
- **次のユーザー作業**: {箇条書き・所要分数つき}
```

以下に「週次ログ」（最新が上）を続ける。
