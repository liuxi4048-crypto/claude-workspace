# 要件定義 — Teacher Co-Pilot MVP

**作成**: 2026-06-25 / **担当**: CPO (build スキル)
**対象Issue**: MOR-86

---

## ターゲットユーザー

公立小中高校の教師。特に以下の業務で時間を取られている：
1. テスト問題作成（1教科あたり2〜3時間）
2. 採点基準・ルーブリック作成
3. 保護者向け連絡文書（MVP外）

## 解決する問題

「学習指導要領に準拠した問題を毎回ゼロから作る必要がある」という時間的負担。
学年・教科・単元を選ぶだけで、5問＋採点ルーブリックが自動生成されれば、作問時間を90%削減できる。

## MVP機能一覧

### Must（今回実装）
- [x] 学年・教科・単元の選択UI（Streamlit サイドバー）
- [x] Claude APIによる問題5問の自動生成（学習指導要領2025年改訂版準拠）
- [x] 観点別採点ルーブリック自動生成（知識・技能 / 思考・判断・表現 / 主体的に学習に取り組む態度）
- [x] Markdownダウンロード
- [x] JSONダウンロード（採点システム連携用）

### Should（次フェーズ）
- 保護者向け連絡文書生成
- 採点支援（答案PDF → 採点コメント生成）
- GIGAスクール補助金申請書類の自動チェック

### Won't（今回スコープ外）
- ユーザー認証・マルチテナント
- クラウドデプロイ（初期はローカル動作）
- 採点後の成績管理

## 技術スタック選定

| 技術 | 理由 |
|---|---|
| Python 3.10+ | Anthropic SDK対応・エコシステム充実 |
| Anthropic SDK (claude-sonnet-4-6) | 高品質な日本語生成・コスト効率 |
| Streamlit | 最速でWebUI構築可能・教師でも使いやすい |
| 構造化出力（JSON） | 問題データの再利用性を確保 |
