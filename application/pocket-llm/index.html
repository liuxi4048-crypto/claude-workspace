🤖 Pocket LLM

⚠️ WebGPU が利用できません

このアプリはブラウザ内でAIモデルを動かすために WebGPU が必要です。

  • Android では Chrome 121 以降をご利用ください(Playストアで Chrome を更新)
  • それでも動かない場合は、Chrome のアドレスバーに chrome://flags と入力し、「Unsafe WebGPU」を Enabled にして再起動してください
  • Samsung Internet / 古い WebView ブラウザは非対応の場合があります

モデルをロード

初回はモデル(数GB)をダウンロードします。Wi-Fi 接続を推奨。2回目以降は端末内キャッシュから読み込み、オフラインでも動作します。

💡 応答が「!!!!」など文字化けする場合は、⚙️設定からより軽いモデル(Gemma 2 2B 日本語版など)に切り替えてください。端末のGPUとの相性の問題です。

0 文字

数式(例: (1200*3 + 480) / 2)は電卓エンジンで正確に計算します。文章題や単位換算はAIが解きます。

このアプリについて

Pocket LLM は、AIモデルをあなたのスマホの中だけで動かすアプリです。

🔒 ローカル実行の利点

  • 完全プライベート: 入力したテキストは端末の外に一切送信されません
  • オフライン動作: 初回のモデルダウンロード後は機内モードでも使えます
  • 無料・無制限: API課金なし、回数制限なし

✅ 得意なこと

  • 要約: 記事・メール・議事録の要約、箇条書き化
  • 文章作成・リライト: メール下書き、敬語への書き換え、校正
  • 翻訳: 日英・英日翻訳(日常文・ビジネス文レベル)
  • 質問応答: 言葉の意味、「〜とは何か」レベルの解説
  • アイデア出し: 企画案の列挙、メリット/デメリット整理
  • テキスト整形: 箇条書き⇔文章の変換、キーワード抽出、分類
  • 簡単な推論・コード: 文章題の立式、短いスクリプトの生成・説明

⚠️ 苦手なこと

  • 正確な計算: AIは計算機ではないため、多桁の計算は間違えます → このアプリでは計算モードの電卓エンジンが正確に計算します
  • 最新情報: 知識はモデルの学習時点まで。オフラインなので検索もできません
  • 超長文: 数万字の一括処理はできません(要約モードは分割をご案内します)
  • 厳密な事実性: 小型モデルは誤答(ハルシネーション)があります。重要な判断には使わないでください
  • 画像・音声: テキスト専用です
