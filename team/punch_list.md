# 指摘トラッキング（Punch List）

> Internal Auditor / Internal Tech Auditor が監査で発見した指摘を記録・追跡する。
> 修正完了まで消さない。クローズ後も履歴として残す。

---

## テンプレート

```
## PL-[番号] — YYYY-MM-DD 発見

**発見者**: Internal Auditor / Internal Tech Auditor
**対象**: [スプリント名 / ファイル名 / プロセス名]
**重大度**: 🔴 重大 / 🟡 中 / 🟢 軽微
**種別**: プロセス / 成果物品質 / 財務 / 技術 / セキュリティ

### 指摘内容
（何が問題か、具体的に）

### 修正条件
（何をすれば解決とみなすか）

### 担当者
（修正責任者: CTO / COO / CFO など）

### 期限
YYYY-MM-DD

### ステータス
🔴 未対応 / 🟡 対応中 / ✅ 完了 / ❌ 却下（理由:）

### 完了確認（Internal Auditor）
- 確認日: YYYY-MM-DD
- 確認結果: 合格 / 再修正必要
```

## エスカレーションルール
