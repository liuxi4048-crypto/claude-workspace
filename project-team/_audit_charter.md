# 監査機関憲章

**モロミーカンパニー（仮） 監査体制 v5.0**

---

## 監査の独立原則

1. 監査役はオーナー（ユーザー）に直属し、COO・CEOの指揮下に入らない
2. 内部監査はプロセスを監視し、外部監査は成果物のみを評価する
3. 外部監査役は内部のやり取りを参照せず、納品物ベースで評価する

---

## 内部監査（Internal Auditor）

| 項目 | 内容 |
|---|---|
| **発動タイミング** | スプリント完了時 / フェーズ完了時 / 問題検知時 — **いずれも日付・完了チェックリストで自動判定**（人間の「内部監査」発語は不要） |
| **対象** | 全プロセス・成果物・財務（Finance Auditorを兼務） |
| **報告先** | オーナー（ユーザー） |
| **権限** | 差し戻し提案権（最終決定はChairman） |

### 自動発動条件（COOが判定）
```
□ CTOの完了報告条件（実装完了・レビュー済・技術的負債記録済）が揃った
□ かつ 直近のスプリント開始から2週間経過 または フェーズ完了基準を満たした
→ 両方Yesなら、COOが人間の確認なしにInternal Auditorを自動召喚する
```

---

## 内部技術監査（Internal Tech Auditor）

| 項目 | 内容 |
|---|---|
| **発動タイミング** | スプリント末のみ — **2週間ごとの日付で自動発動**（CTOの完了報告と連動） |
| **対象** | 技術プロセス（実装品質・設計準拠） |
| **報告先** | Internal Auditor → オーナー |
| **権限** | 技術的指摘・改善提案 |

---

## 外部監査（External Auditor）

| 項目 | 内容 |
|---|---|
| **発動タイミング** | 本番リリース前 / 四半期末 / 重大判断時のみ（固定） |
| **対象** | 成果物のみ（内部プロセス不参照） |
| **報告先** | オーナー（ユーザー）のみ。COO・CEOには非共有 |
| **権限** | 独立評価レポート提出・差し戻し提案権 |
| **制約** | 自発的な召喚は不可。オーナーまたは固定タイミングのみ |

---

## 監査スケジュール（固定）

| タイミング | 実施内容 |
|---|---|
| **本番リリース前（必須）** | External Auditorが成果物＋技術を一括独立審査 |
| **Q1/Q2/Q3/Q4 末** | External Auditorが定期評価レポートをオーナーへ提出 |
| **重大判断時（随時）** | 大型契約・組織変更・大規模投資 |
| **スプリント末** | Internal Tech AuditorがCTOプロセスを監査 |
| **フェーズ完了** | Internal Auditorが全体監査 → Chairmanへ報告 |
