# 意思決定ログ

> Chairman が裁定を下した際に必ずこのファイルへ記録する。
> 記録者: Chairman → COO が確認・保存

---

## テンプレート

```
## DL-[番号] — YYYY-MM-DD

**議題**: （何を決めたか）
**トリガー**: `CEO判断` / `提案審議` / `フェーズ完了` / その他

### CEO-Ext の立場
（外向き・収益・スピード観点からの主張）

### CEO-Int の立場
（内向き・品質・実現性観点からの主張）

### Chairman 裁定
- **結論**: [採用] / [折衷案] / [差し戻し]
- **理由**: （なぜその裁定か）
- **条件**: （差し戻し・折衷案の場合のみ）

### COO 実行計画
（裁定後に落とし込んだ具体アクション）

### 2週間後レビュー（YYYY-MM-DD）
- 結果: （裁定は正しかったか）
- 学び: （次回に活かすこと）
```

---

## 召喚基準（CEO判断が必須になる条件）

以下のいずれかに該当する場合、COOは自動的に `CEO判断` を発動する。

| 基準 | 閾値 |
|---|---|
| 予算 | ¥50,000 以上 |
| 期間 | 1ヶ月以上のプロジェクト |
| 技術 | 未経験・未検証の技術スタックを含む |
| 契約 | 新規クライアントとの契約 |
| 組織 | チーム体制の変更 |
| リスク | CLO または CISO が「高リスク」と判定 |
