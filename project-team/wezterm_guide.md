# WezTerm チーム運用ガイド

---

## ユーザーが行うこと（これだけ）

```
┌────────────────────────────────────────────┐
│  1. CTRL+ALT+0  → COOペインを開く          │
│  2. 「作業開始」と入力する                  │
│  3. 作業が終わったら「作業終了」と入力する   │
└────────────────────────────────────────────┘
```

**ペインの開閉・メンバーの召喚・レイアウト選択はすべてCOOが行う。**

---

## COOが自律的に行うこと

| タイミング | COOの行動 |
|---|---|
| `作業開始` | 前回日報を確認 → 本日タスクを整理 → 必要なメンバーのペインを開く |
| タスク発生 | タスク種別を判断 → 該当メンバーを召喚（ペインを開く） |
| メンバーが完了 | 結果を受け取る → 次のメンバーへバトンタッチ（ペインを開く） |
| `作業終了` | 各部門の日報を収集 → 統合日報を作成 → 全ペインをクローズ |
| スプリント末 | 監査ペインを開く → レトロスペクティブを実施 |

---

## COOが使うペイン召喚コマンド

COOがメンバーを召喚する際に内部で実行するコマンド（ユーザーは意識不要）。

```powershell
# 新タブでメンバーを召喚
pwsh -File "C:\Claude\team\launch\summon.ps1" -Member [名前] -Layout Tab

# 右ペインに分割して召喚
pwsh -File "C:\Claude\team\launch\summon.ps1" -Member [名前] -Layout Right -Percent 50

# セッション終了（全ペインクローズ）
pwsh -File "C:\Claude\team\launch\dismiss.ps1"
```

## 緊急時のみ使うキーバインド

通常は使わない。COOが応答しない・フリーズした場合のオーバーライド用。

| キー | 内容 |
|---|---|
| `CTRL+ALT+SHIFT+1` | CEO対立議論を強制起動 |
| `CTRL+ALT+SHIFT+2` | Chairman を強制起動 |
| `CTRL+ALT+SHIFT+3` | AIガバナンス三者を強制起動 |
| `CTRL+ALT+SHIFT+4` | スプリント末監査を強制起動 |
| `CTRL+ALT+SHIFT+5` | 提案作成レイアウトを強制起動 |

---

## ペインの基本操作（必要になったら使う）

| 操作 | キー |
|---|---|
| ペイン移動 | `CTRL+SHIFT+H/J/K/L` |
| ペイン拡大 | `CTRL+SHIFT+Z` |
| タブ切り替え | `ALT+数字` |

---

## ファイル書き込みルール（競合防止）

COOが複数ペインを管理する際の書き込み分離ルール。

| メンバー | 書き込むファイル |
|---|---|
| COO | `daily_reports/summary_coo.md` / `retro_log.md` |
| 各CxO | `daily_reports/[役職名].md` |
| Chairman | `decision_log.md` |
| Internal Auditor | `punch_list.md` |

同じファイルへの同時書き込みは禁止。順番待ちはCOOが調整する。

